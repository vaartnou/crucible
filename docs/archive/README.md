# Archive

Files in this directory are superseded by the v2 economics
(`fleetbase-physical-economics-v2`) and are kept for history only. Do not compare
their numbers with v2 scores.

- [fleetbase-findings.md](fleetbase-findings.md): v1 paired pilot findings.
- [fleetbase-validation-v1.md](fleetbase-validation-v1.md): v1 infrastructure
  validation attempts and numbers.
- [fleetbase-pilot-results.json](fleetbase-pilot-results.json): sanitized
  completed outcomes of the v1 pilot (`fleetbase-physical-economics-v1`). JSON
  cannot carry an annotation, so this README records that it is superseded.
